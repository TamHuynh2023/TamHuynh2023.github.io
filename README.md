# tamhuynh2023.github.io

Developer website for Tam Huynh's games (GitHub Pages, served from `main`).

- `app-ads.txt` — AdMob authorized sellers; must stay at the domain root. Line comes from AdMob → Apps → app-ads.txt.
- `pikachu3d/privacy.html` — Tiny Beasts Onet 3D (formerly Pikachu 3D) privacy policy (URL used in Play Console).
- Play Console → Store listing → Contact details → Website must be `https://tamhuynh2023.github.io` so AdMob finds `app-ads.txt`.
